# ADR-0008: Arabic-first UI

- Status: Accepted
- Date: 2026-08-15

## Context

The platform needs a stable foundation before product domains are introduced.

## Decision

Design the web experience Arabic-first with RTL and LTR support.

## Consequences

Directionality, localization, layout, and testing are architectural concerns from the start; a full design system is not part of C00.

## C00 scope

This record accepts the direction; production implementation belongs to the relevant later milestone.
